# Ten Interval Exercises Design

## Goal

Expand the Grade 5 interval practice session from six to ten unique major/minor-third questions.

## Scope

- Preserve the current six questions, notation, audio, and answer flow.
- Add E–G♯, E–G, F–A, and F–A♭ as four new questions.
- Render notation from written staff positions, with accidentals changing audio without shifting a note to another line or space.
- Keep the practice UI unchanged apart from its "of 10" count and completion total.

## Validation

- Each new major third is 4 semitones and each new minor third is 3 semitones.
- Each written pair is diatonically a third.
- E–G♯ is written on the G line; F–A♭ is written in the A space.
- The session references ten unique notation assets.
